Welcome to your new portfolio! This blog post is a demonstration of how Jekyll renders markdown files in the `_posts/` folder into fully styled articles.

## How to customize this website

You don't need to dive deep into HTML templates to customize this portfolio. All major structures are dynamic and configurable:

1. **Global configuration**: Update `_config.yml` in the root folder with your name, roles prefix, social handles, timezone, and avatar image path.
2. **Projects catalog**: Add or modify items in `_data/projects.yml`. Supported categories include `projects`, `certifications`, `badges`, and `vibe coding`.
3. **Resume items**: Update `_data/resume.yml` with your professional experience chronological items, education milestones, core skills, and tooling arrays.

## Running this site locally

To test this Jekyll portfolio locally before deploying to GitHub Pages, execute the following commands in your terminal:

```bash
# Install dependencies
bundle install

# Start the local development server
bundle exec jekyll serve
```

Navigate to `http://localhost:4000` in your web browser to view the site. Changes you make will be auto-compiled in real time!
